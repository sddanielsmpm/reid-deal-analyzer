# Event Taxonomy

Use this file to define conversion and funnel tracking before implementation.

## Core Events

- `page_view`
- `cta_click`
- `form_start`
- `form_step_view`
- `form_field_error`
- `form_submit`
- `lead_created`
- `partner_redirect`
- `thank_you_view`

## Naming Rules

Use lowercase snake case for event names. Include `page_type`, `offer`, `form_id`, `step_number`, `partner_id`, and `traffic_source` when available.
